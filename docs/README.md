# Ulan Alert Documentation

Welcome to the documentation for **Ulan Alert**, a software-only smart-clothesline prototype that demonstrates synthetic environmental monitoring, rain-warning logic, supervised machine learning, and a user-facing interface.

This documentation is written for students, evaluators, facilitators, developers, and readers who want to understand the project without having to interpret the source code first.

## Important terminology

- **Synthetic data:** readings generated by software rather than collected from a physical sensor.
- **Simulation:** a controlled software environment that produces weather-like conditions and events.
- **Rain-plate state:** whether the simulated rain sensor is considered wet. It remains wet briefly after rainfall ends to represent sensor dry-off delay.
- **Prediction:** the model's estimated probability that the rain plate will become wet within the defined future window.
- **Warning:** a user-facing state determined by the probability, configured thresholds, consecutive readings, and rain state.
- **Scenario:** a preset or operating mode used to demonstrate a particular simulated weather condition.

## Scope and accuracy

The repository describes itself as a **software-only prototype**. It does not require or connect to an ESP32, physical rain plate, light sensor, temperature/humidity sensor, MQTT broker, buzzer, LED, or motorized actuator. Python generates the readings; the frontend presents them and the backend supplies model predictions.

The application does not retrieve live meteorological forecasts. Location selection changes the simulator's geographic and climate inputs; it does not turn the application into a live weather service. Model performance measured against generated data is simulation-based performance, not field accuracy.
